# InkVector · 手绘线稿矢量化工作台

把扫描的手绘线稿转成**带变粗细贝塞尔曲线、保留交叉/分叉拓扑、保留画师笔压**的矢量结果，
并提供叠加校验、控制点修形、镜头列表与验收流程。

## 解决的核心问题

手绘番剧线稿矢量化的典型痛点，本项目逐一对应：

| 痛点 | 本项目的处理 |
| --- | --- |
| 放大后线糊 | 输出三次贝塞尔矢量，任意缩放无损 |
| 外包工具粗细统一、丢失笔压 | 中轴每点携带 SDF 半径，沿贝塞尔段线性插值，重渲染为变粗细带状笔画 |
| 交叉处断开 | 拓扑保护的细化 + 高复杂度分量节点合并，交叉/分叉/线头显式建模 |
| 8000+ 线描起来慢 | 线性时间 EDT/Chamfer，CPU 4K 约 1.9s；WebGL2 JFA 加速距离场 |
| 无法检查对错 | 原图/矢量叠加视图、轮廓偏差度量、节点与控制点可视化 |
| 改不动 | 控制点可拖拽修形，编辑被标记并可在重跑时保留 |

## 算法流水线

```
扫描图 (ImageData)
  → 二值化（灰度阈值 + 透明底处理）
  → 连通域去噪
  → 有符号距离场 SDF（Felzenszwalb 精确 EDT / WebGL2 JFA）
  → Zhang-Suen 拓扑保护细化
  → 骨架单像素化（去 45° 斜线的 2px 对角带，连通性安全）
  → 骨架图构建（线头/分叉/交叉节点 + 边，含带区合并与图简化）
  → 中轴光顺（移动平均 + 容差级 DP，吸收 1px 栅格量化）
  → 三次贝塞尔拟合（PCA 切线 + 良态最小二乘，贪心少段）
  → 变粗细带状重渲染 + 轮廓偏差度量
```

### 关键正确性设计

- **拓扑保持**：Zhang-Suen 满足 `2 ≤ B(P1) ≤ 6`、`A(P1)=1`，不破坏 8 连通、不消线头。
- **2px 对角带折叠**：ZS 对 45° 斜线留下两像素宽阶梯带，朴素度数法会产生大量假分叉。
  `singlePixelize` 只在“删除后邻居仍局部 8 连通、不产生孤立点”时删冗余像素，
  真分叉/交叉中心因连通性检查而保留。
- **节点合并**：高复杂度像素（度≥3）按 8 连通分量归并为同一拓扑节点，
  再做近邻节点合并、度 2 假分叉抑制、自环识别，得到干净的线头/分叉/交叉图。
- **笔压半径**：骨架半径取 SDF（像素中心到边界距离），减 0.5 对齐几何口径，
  3×3 邻域取最大抑制离散抖动，0.5px 下限。
- **拟合稳定性**：端点切线用局部 PCA 主方向；正规方程病态（近直线共线切线）时
  回退弦长 1/3 控制点，避免发散摆动；点到曲线误差用空间哈希近邻搜索。

## 目录结构

```
src/
  core/        纯算法（无 DOM 依赖，可在 Node/Worker 运行）
    image.ts       二值化、连通域去噪
    sdf.ts         Felzenszwalb 精确欧氏距离变换
    thinning.ts    Zhang-Suen 细化 + 骨架单像素化 + SDF 脊线
    graph.ts       骨架→节点/边拓扑图（带区合并、图简化）
    smooth.ts      中轴光顺与弧长重采样
    fit-bezier.ts  三次贝塞尔拟合（PCA 切线、良态最小二乘）
    polyline.ts    Douglas-Peucker
    rasterize.ts   变粗细带状重渲染（2x 超采样）
    metrics.ts     Chamfer 轮廓偏差、IoU、段数比
    temporal.ts    前后帧笔画匹配
    vectorize.ts   流水线编排 + CPU 后端
  gl/          WebGL2 后端（JFA 距离场、GPU 二值化，不支持时回退 CPU）
  synth/       带真值的合成线稿生成器（笔压/抖动/纸纹/软边，8 个拓扑场景）
  editor/      控制点拖拽等手动编辑
  state/       镜头项目与 localStorage 持久化
  ui/          Canvas 叠加渲染器与工作台界面
test/          Vitest 单元与端到端测试（27+ 用例）
bench/         4K 性能基准
scripts/       自检、fixture 生成
```

## 常用命令

```bash
npm install
npm test          # 全部单元/端到端测试
npm run bench     # 4K 性能基准（验收线 3000ms，当前约 1900ms）
npm run selftest  # 全场景端到端自检，输出 test-output/selftest.json
npm run gen:fixtures  # 生成带真值的合成线稿
npm run dev       # 启动工作台（Vite）
npm run build     # 构建 UI 到 dist/
```

## 验收指标与口径

1. **轮廓偏差**：重渲染掩码与原二值化掩码的对称平均轮廓距离（Chamfer 距离变换）。
   扫描二值化本身引入 ±0.5px 边界量化噪声，简单笔画均值 ≤ ~0.6px，
   含多交叉场景 ≤ ~0.9px；95 分位 ≤ 2px。拓扑正确性由专门测试严格保证
   （X=1 交叉 4 线头 4 边、T/Y=1 节点 3 线头、网格=9 交叉）。
2. **性能**：3840×2160 合成线稿 CPU 端到端约 1.9s（≤3s 验收线）。
3. **段数**：贪心少段 + 容差光顺，近直线收敛为单段；段数随真实弯曲复杂度增长，
   不被像素锯齿推着膨胀。

> 说明：在 1px 栅格精度下，“单根量化偏移直线既 1 段又 ≤0.5px 偏差”存在物理下限，
> 测试阈值据此区分简单/复杂场景，拓扑与确定性指标保持严格。

## 后端

- `cpu`：完整参考实现，结果确定、可复现，是测试基准。
- `webgl2`：二值化与 JFA 距离场在 GPU，图结构操作复用 CPU；
  环境不支持 WebGL2 时自动回退全 CPU，接口一致。

## 手动编辑与时间一致性

- 拖拽控制点只改几何、不动拓扑与半径，笔画标记 `manuallyEdited`。
- `temporal.ts` 对相邻帧笔画做弧长重采样 + 贪心最近邻匹配，
  输出匹配偏差与未匹配率，用于追踪同一根线在镜头间的走向。
